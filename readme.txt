== Installation ==

Installing EventKoi Lite is easy.

= Installation =

1. In your WP Admin, select Plugins, then Add plugin.
2. In the Search Plugins field, type in "EventKoi Lite"
3. When you find EventKoi Lite, click on Install Now.
4. The installation will run, then click on Activate.

= Configuring your events calendar =

1. Once the plugin is activated, head to Events, then Settings.
2. From there you can configure when you week starts, your working days, and 12/24-hour clock.

= Create your first event =

1. Head to Events > Events and select Add event
2. Fill out the form to create your event.

= Add your calendar to your site =

Head to Events > Calendar and select **Default calendar**. Then select the **Embed** tab.
There, you will see 3 ways to embed the calendar into your site:

1. Your calendar comes with a default link. Out of the box, the link is: https://yourwebsite.com/calendar/default-calendar/
2. Using either shortcodes in any page or post: [eventkoi_calendar display=calendar] or [eventkoi_calendar display=list] depending on whether you want a calendar or list view.
3. Adding a block in any page or post: Type in "/eventkoi" and then select either "EventKoi Calendar" or "EventKoi List" depending on whether you want a list or calendar view.

== Frequently Asked Questions ==

= What is the best way to add an events calendar to WordPress? =
Install EventKoi Lite, create your events, then add the EventKoi Calendar block or the [eventkoi_calendar] shortcode to any page. You can also use the Elementor widget, Beaver Builder module or Divi module.

= Does it work with block themes and classic themes? =
Yes. EventKoi Lite works with both block and classic themes. Use the blocks or shortcodes to build your events calendar.

= Can I show a responsive events calendar on mobile? =
Yes. The events calendar is fully responsive and mobile-friendly, with keyboard navigation and ARIA labels.

= Can I sell event tickets on my own WordPress site? =
Yes. EventKoi Lite includes event ticketing powered by WooCommerce. Create multiple ticket types per event with their own price and capacity, and accept payments through any WooCommerce gateway, including Stripe and PayPal. Buyers get a confirmation email with a check-in code.

= Does EventKoi charge a fee per ticket? =
EventKoi Lite does not take a cut of your ticket sales. Your payment gateway's normal processing fees still apply.

= Can I create free and paid ticket types for the same event? =
Yes. Set a ticket price to 0 for free tickets or any amount for paid tickets, and mix both on one event.

= Does EventKoi Lite support event registration and RSVP? =
Yes. Set capacity, collect attendee sign-ups, send confirmation emails with check-in codes, and manage check-ins from your WordPress admin.

= Does EventKoi Lite work with Stripe and PayPal for ticket sales? =
Yes. EventKoi uses WooCommerce's standard checkout, so any WooCommerce payment gateway works, including Stripe and PayPal.

= Does EventKoi Lite include recurring events? =
Recurring events are available in EventKoi Pro. Pro supports daily, weekly, monthly and yearly recurring events with advanced rules.

= I'm using The Events Calendar. Can I migrate my events to EventKoi? =
Yes. The built-in migration tool imports your events from The Events Calendar, including dates, venues, categories, recurrence rules and featured images. Already-migrated events are skipped, so you can run it more than once safely.

= Can I import events from Google Calendar, Apple Calendar or Outlook? =
Yes. Export your calendar as an .ics file and import it from the Import tab in the EventKoi settings.

= Does EventKoi Lite support virtual events and timezones? =
Yes. You can create virtual events, and the calendar detects each visitor's timezone so they see events in their local time. You can also set a fixed timezone for an individual event.

= Does it work with Elementor, Beaver Builder and Divi? =
Yes. EventKoi Lite includes native Elementor widgets and templates, Beaver Builder modules and Divi 5 modules.

= My calendar or event page shows "Page not found." =
Go to Settings > Permalinks and click Save Changes to refresh rewrite rules.

= Can I customize the event template? =
Yes. On a block theme, go to Appearance > Editor > Templates and customize the Event template. On a classic theme, you can edit the template files.

= Does EventKoi Lite help my events appear in Google Search? =
Yes. It adds JSON-LD structured data to every event page so Google can understand your events and show them as rich results. No setup needed.


== External services ==

This plugin can connect to the **Google Maps JavaScript API** in order to display interactive maps inside event and calendar views.
It sends your configured Google Maps API key (if provided) along with requests made by the visitor's browser when viewing a page that contains an embedded map. No personal data is sent by the plugin itself, but Google may collect usage data in accordance with their policies. This connection only happens if maps are enabled in the plugin settings and a page with an event location map is viewed.
This service is provided by Google LLC: [Terms of Service](https://cloud.google.com/maps-platform/terms), [Privacy Policy](https://policies.google.com/privacy).
